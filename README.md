# FarmGuide

Аддон для World of Warcraft (Retail, Midnight 12.x): маршруты сбора руды и трав, полноэкранный HUD, аналитика аукциона и подсказки. Без зависимостей от других аддонов.

## Возможности

- **Автозапись точек.** Каждый сбор руды или травы запоминается с координатами и добычей. Повторные сборы в одном месте сливаются в одну точку спавна.
- **Маршрут.** Из собранных точек строится кратчайший замкнутый круг по зоне (ближайший сосед + 2-opt). Новые точки сразу добавляются.
- **HUD на весь экран.** Линия маршрута, иконки точек, стрелка и расстояние до следующей точки, вращение вместе с персонажем. Клики проходят сквозь HUD.
- **Рейтинг зон.** Золото в час по каждой зоне по ценам вашего сервера.
- **Аукцион.** Точные цены собранных ресурсов, история цен, поиск дешёвых лотов и выгодных перепродаж. Покупки делаются вручную.
- **Подсказки.** Где фармить выгоднее, что подешевело или подорожало, полные сумки, устаревшие цены.
- **Интерфейс.** Кнопка у мини-карты, меню аддонов Blizzard, окно с вкладками, ползунки и галочки для всех настроек.

## Установка

1. Скачайте репозиторий (**Code → Download ZIP**) и распакуйте.
2. Переименуйте папку в `FarmGuide`, если она называется иначе (например, `FarmGuide-main`).
3. Положите её в `World of Warcraft\_retail_\Interface\AddOns\`.
4. Если аддон помечен как устаревший, включите «Загружать устаревшие модификации» в списке аддонов.

## Использование

- **ЛКМ по кнопке у мини-карты** — главное окно, **ПКМ** — настройки HUD, **Shift+ЛКМ** — HUD вкл/выкл.
- На аукционе появляется панель FarmGuide с кнопками «Скан ресурсов» и «Полный скан».
- В новой зоне первый проход делаете сами: собирайте всё, что видите. Через 15–20 сборов маршрут уже нормальный.

Команды для тех, кто предпочитает чат: `/fg`, `/fg hud`, `/fg next`, `/fg zoom N`, `/fg rotate`, `/fg dim N`, `/fg filter ore|herb|both`, `/fg profit N`, `/fg resetzone yes`.

## Ограничения

- Аддоны WoW не имеют доступа к интернету, поэтому маршруты и цены собираются внутри игры.
- Узнать, что ресурс есть впереди, нельзя: аддон ведёт по известным местам спавна.
- Аддон не автоматизирует сбор и движение. Это запрещено правилами игры, и API этого не позволяет.

## Структура

| Файл | Назначение |
|---|---|
| `Core.lua` | события, база данных, координаты, цены, форматирование |
| `Gather.lua` | распознавание сбора, запись точек, статистика сессии |
| `Route.lua` | построение маршрута |
| `Prices.lua` | сканы аукциона, история цен, сделки |
| `HUD.lua` | полноэкранный HUD |
| `UI.lua` | главное окно, вкладки, подсказки, команды |
| `Options.lua` | настройки, кнопка у мини-карты, интеграция с меню Blizzard |
